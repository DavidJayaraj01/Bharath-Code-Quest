Smart Pill Dispenser

  • State machine: LOCKED → DOSE_WINDOW → DISPENSED/MISSED
  • Real-time WebSocket event streaming
  • Adherence rate calculation & tracking
  • Miss-dose alerts to ASHA workers & family
  • Manual demo controls for live presentations

Hardware-Ready Design

The simulator produces the exact BLE GATT event format a physical ESP32 dispenser would emit. Swapping in real hardware requires changing only the event source — no architecture change needed.
